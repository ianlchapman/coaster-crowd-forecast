# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately using GitHub's
[private vulnerability reporting](https://github.com/ianlchapman/coaster-crowd-forecast/security/advisories/new).
Do not open a public issue for security problems.

This is a personal project maintained on a best-effort basis. I aim to
acknowledge reports within a week.

## Scope

Only the latest commit on `main` is supported. The repository ships no
third-party data and no credentials; if you find either, please report it.
